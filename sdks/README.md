# PEMRIX SDKs

This directory contains developer SDKs for the PEMRIX network.

| SDK | Status | Path |
|---|---|---|
| Rust | ✅ Active | `crates/pemrix-sdk` |
| TypeScript | 🚧 Mock stub | `sdks/typescript` |
| Python | 🚧 Mock stub | `sdks/python` |
| Go | 🚧 Mock stub | `sdks/go` |

The TypeScript, Python, and Go packages currently provide mock clients that mirror
the Rust SDK interface. Real HTTP/gRPC transports will be wired in once the
public testnet is deployed.
