# PEMRIX Marketing & Docs Site

Next.js + Fumadocs site for [pemrix.com](https://pemrix.com) and [docs.pemrix.com](https://docs.pemrix.com).

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Building for Production

```bash
pnpm build
```

## Docs Structure

Docs live in `content/docs/` as MDX files managed by Fumadocs.
