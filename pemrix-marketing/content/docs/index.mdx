# Welcome to PEMRIX

PEMRIX is an open blockchain designed for global payments, merchant settlement, and AI-native applications.

## What is PEMRIX?

- **Open blockchain** — no single company controls it.
- **Fast finality** — transactions settle in seconds.
- **Crypto-agile** — ready to migrate to post-quantum signatures.
- **Built for payments** — simple UX like UPI, global reach like crypto.
