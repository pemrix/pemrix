# Security

Security is central to PEMRIX. The network combines decentralized consensus, audited cryptography, and crypto-agile signatures to protect users and assets.

## Network security

- **Decentralized validators** — no single entity controls block production.
- **Economic finality** — validators stake PRX and can be slashed for misbehavior.
- **Audited code** — core protocol and smart contract tooling undergo regular audits.

## User security

- Keep recovery phrases offline and in multiple secure locations.
- Be cautious of phishing sites and fake wallet apps.
- Enable app lock and biometric authentication where available.

## Post-quantum readiness

PEMRIX is designed to migrate signature schemes as post-quantum standards mature, protecting long-term assets.
