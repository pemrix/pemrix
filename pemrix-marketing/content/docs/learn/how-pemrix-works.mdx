# How PEMRIX works

PEMRIX uses a delegated proof-of-stake consensus mechanism operated by a globally distributed set of validators.

## Network layers

1. **Consensus layer** — validators agree on the ordering and finality of transactions.
2. **Execution layer** — smart contracts and account balances are updated.
3. **Application layer** — wallets, merchants, exchanges, and AI agents interact with the network.

## Fast finality

Once a block is finalized, transactions are irreversible. This enables instant merchant settlement and real-time payments.

## Crypto-agility

PEMRIX supports multiple signature schemes and can be upgraded to post-quantum cryptography through on-chain governance.
