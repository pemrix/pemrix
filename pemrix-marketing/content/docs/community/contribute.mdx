# Contribute

PEMRIX is an open-source protocol. Contributions are welcome from developers, writers, designers, and community organizers.

## Ways to contribute

- **Code** — open issues and pull requests on GitHub.
- **Documentation** — improve guides and translations.
- **Translation** — help localize the wallet and docs.
- **Community** — answer questions and organize events.
- **Grants** — apply for ecosystem grants to build on PEMRIX.

## Getting started

1. Join the [Discord](https://discord.gg/pemrix).
2. Find a good first issue on GitHub.
3. Read the contribution guidelines in each repository.

Thank you for helping build the open network for value.
