# Wallets

To use PEMRIX, you need a wallet that supports the network.

## PEMRIX Wallet

The official wallet is the easiest way to get started. It supports:

- Sending and receiving PRX
- QR-based payments
- Merchant checkout
- Staking and governance

## Other wallets

Developers and advanced users can use command-line wallets or hardware wallets for additional security.

## Create your first wallet

1. Download PEMRIX Wallet from the official site.
2. Create a new wallet and back up your recovery phrase.
3. Fund your wallet with PRX.
4. Start sending payments or interacting with apps.
