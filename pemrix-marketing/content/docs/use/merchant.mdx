# Merchant checkout

PEMRIX Merchant provides tools to accept PRX and stable-asset payments online and in-store.

## Features

- **QR checkout** — customers scan and pay in seconds.
- **Payment links** — share links via messaging, email, or social media.
- **Invoicing** — create and track invoices from the merchant dashboard.
- **Instant settlement** — funds arrive directly to your wallet.

## Integration options

- No-code payment buttons and hosted checkout
- REST API and SDKs for custom integrations
- Plugins for popular e-commerce platforms

## Get started

Visit [merchant.pemrix.com](https://merchant.pemrix.com) to create your merchant account.
