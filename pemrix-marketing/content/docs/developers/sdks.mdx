# SDKs

PEMRIX provides official SDKs to make building on the network easier.

## Official SDKs

- **TypeScript** — `@pemrix/sdk` for browser and Node.js apps.
- **Python** — `pemrix-py` for backends and data pipelines.
- **Go** — `github.com/pemrix/go-sdk` for high-performance services.

## Community SDKs

Community members maintain SDKs for additional languages. Always verify the source before using third-party packages.

## Installation

```bash
# TypeScript
npm install @pemrix/sdk

# Python
pip install pemrix-py

# Go
go get github.com/pemrix/go-sdk
```
