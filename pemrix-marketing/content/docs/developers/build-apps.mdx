# Build apps

PEMRIX provides developer tooling to build wallets, merchant integrations, DeFi apps, and AI agents.

## Developer stack

- **RPC API** — query the chain and send transactions.
- **SDKs** — available for TypeScript, Python, and Go.
- **Smart contracts** — deploy logic with PEMRIX-compatible execution environments.

## Getting started

1. Get testnet PRX from the [faucet](https://faucet.pemrix.com).
2. Connect to the testnet RPC endpoint.
3. Use the SDK to create an account and send a transaction.

## Example

```typescript
import { PemrixClient } from "@pemrix/sdk";

const client = new PemrixClient({ network: "testnet" });
const balance = await client.getBalance(address);
```
