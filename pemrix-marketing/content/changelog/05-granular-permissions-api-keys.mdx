---
title: 'Granular permissions and scoped API keys'
date: 'FEB 28 2025'
id: '05'
---

Workspace admins can now assign fine-grained roles and issue API keys limited to specific repos, environments, and actions.

- **Custom roles** — combine permissions for runs, secrets, runners, and billing without full admin access
- **Scoped API keys** — restrict keys to read-only logs, trigger runs, or manage runners per repository
- **Audit log export** — download permission and key lifecycle events as CSV for compliance reviews
- **SSO group mapping** — map IdP groups to Relay roles on Enterprise plans

Also in this release:

- API keys inherit the creating user’s permissions until explicitly scoped
- Deprecated global write tokens; existing tokens remain valid until rotated
- Fixed a bug where read-only members could approve deploy gates on protected branches

See [AI prompts](/docs/ai-prompts) for automation examples using scoped keys.
