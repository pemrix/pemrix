Relay 1.0 is here. Define CI/CD pipelines in `relay.yaml`, run them on managed cloud runners, and ship preview environments on every pull request.

- **Pipelines as code** — version-controlled `relay.yaml` with jobs, steps, matrix builds, and deploy gates
- **Relay CLI** — install with `npm i -g @relay/cli`; scaffold projects with `relay init` and trigger runs with `relay run`
- **Preview environments** — automatic deploy per PR with unique URLs and teardown on close
- **Remote caching** — share dependency and build caches across branches and teammates
- **Cloud runners** — Linux, macOS, and Windows targets with no agent setup
- **Insights dashboards** — build duration, success rate, and queue time at a glance

From commit to production, without the wait. [Get started](/docs/getting-started) or read [What is Relay](/docs).
